**ロシア語アルファベットの 33 文字で構成されたダーク中世 RPG — カードバトル、呪文、そして WebSocket によるマルチプレイ。**

> **技術:** Godot 4.6 / GDScript · 重苦しい中世世界観 · WebSocket によるリアルタイムマルチプレイ（Node + ws リレー）。ネイティブ解像度 1280×720。

## 概要

BOOKWAR は、進行のすべてがロシア語アルファベットに連動した RPG です。現代ロシア語アルファベットは **33 文字** あるため、ゲームは **難易度が段階的に上がる 33 レベル** で構成されています。各レベルは新しい文字をアンロックする手調整の地域で、各文字はプレイ可能な戦闘カードになります。

文字は言語的な役割で分類されます:
- **母音**（А、О、Е…）は **ダメージ**（攻撃）を与える。
- **子音**（К、Т、Б…）は **シールド / 防御** を付与する。
- **記号**（Ъ、Ь）は他のカードを強化する **バフ** として働く。

倒したモンスターは文字を落とし、それをターン制 **カードバトル** で消費し、**呪文**（単語）に組み合わせます。各文字は 1 回の戦闘で 1 度しか出せないため、手持ちの充実が鍵になります。第 33 の最終レベル「文字の井戸」は、邪悪な「禁令の番人」を相手にした大乱戦です。

## 特徴

- ロシア語アルファベット 33 文字に連動した **33 レベルの進行**。
- **ターン制カードバトル** — 文字カードを出し、HP とシールドを管理し、逃走やオート戦闘も可能。
- **呪文** — 集めた文字で単語を組み立て、ゲーム内通貨でアンロック。
- **WebSocket マルチプレイ** — 共有ワールド、チャット、文字の取引、PvP 決闘への招待。
- 33 のテーマ別地域（光の谷 → 文字の井戸）に広がる **ダーク中世の世界観**。
- クロスプラットフォーム：Godot エディタで実行可能、**HTML5** と **Android** に書き出し対応。

## 動作環境と起動

- **Godot 4.6**（初回オープン時に `.godot/` のインポートキャッシュが再生成されます）。

**エディタから:**
1. `git clone https://github.com/zuluchakahuaka-nwc/bookwar`
2. Godot 4.6 で `project.godot` を開く。
3. **F5** で実行（メインシーン：`scenes/ui/main_menu.tscn`）。

**または書き出し:** 同梱の `export_presets.cfg` を使用（HTML5 / Android）。

デフォルト操作：**WASD** 移動 · **E** 調べる · **I** インベントリ · **T** 会話 · **F** 攻撃 · **H** マニュアル · **Space** 一時停止。

## マルチプレイ

マルチプレイはオプションの WebSocket リレーサーバ（`multiplayer/server.js`、Node + `ws`、既定ポート `4567`）です:

- **ホスト:** `node multiplayer/server.js`
- **参加（Web 版）:** `wss://<host>/ws` に自動接続（nginx プロキシ経由）。`?mp=ws://host:port` で上書き可能。
- **参加（ネイティブ）:** `ws://localhost:4567` にフォールバック（`DIRECT_FALLBACK_URL` を編集、または URL を指定）。

プロトコル：WebSocket メッセージ 1 件につき JSON オブジェクト 1 つ（在席、位置、チャット、文字、取引、対戦招待）。
